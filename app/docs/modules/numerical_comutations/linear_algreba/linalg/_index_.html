OVERVIEW

Linear algebra for numerical computing.

The onithrasml.linalg module provides numerical algorithms for working with vectors and matrices. It forms the mathematical foundation for optimization, statistics, machine learning, scientific simulation, and other numerical workloads.

OnithrasML is gradually expanding its linear algebra layer. The documentation therefore separates the API into functionality that is currently available and functionality planned for future releases.

i
API availability

Only APIs marked Available should be considered part of the current public API. APIs marked Planned represent the future direction of the module.

DESIGN

A familiar API, built for OnithrasML.

The design takes inspiration from established scientific Python conventions while keeping the API focused on OnithrasML's numerical computing architecture.

01
NumPy-compatible inputs

Numerical arrays remain the primary data representation.

02
Specialized algorithms

Algorithms should use the appropriate numerical method instead of unnecessary work.

03
Numerical correctness

Stability, tolerances, conditioning, and residuals are treated as first-class concerns.

→
Which routine should I use?

If you need \(x\) from \(Ax=b\), start with solve(). Do not calculate inv(A) @ b unless you specifically need the inverse itself.

ƒ
Matrix functions

Matrix functions are not the same as applying an element-wise function to every entry. For example, \(e^A\) is a matrix exponential, not np.exp(A).

Why this matters

High-level APIs should remain the preferred interface for most users. Low-level BLAS and LAPACK access is intended for advanced optimization, custom numerical kernels, and performance-sensitive workloads.

USER GUIDANCE

Which linear algebra routine should I use?

Problem Recommended API Why
Solve \(Ax=b\) solve Avoids unnecessary explicit inversion.
Need \(A^{-1}\) inv Directly computes the inverse.
Approximate system lstsq Minimizes the least-squares residual.
Non-square inverse pinv Uses the Moore-Penrose pseudo-inverse.
Understand spectrum eig Computes eigenvalues and eigenvectors.
Low-rank structure svd Exposes singular values and directions.
Positive-definite matrix cholesky Efficient factorization for SPD matrices.
Orthogonal factorization qr Useful for least squares and numerical algorithms.
NUMERICAL STABILITY

Correct mathematics is not enough.

Numerical linear algebra operates with finite-precision floating-point arithmetic. The implementation therefore needs to consider conditioning, rounding error, pivoting, tolerances, and residuals.

01

Conditioning

Poorly conditioned matrices can amplify small input errors.

02

Pivoting

Pivoting can improve numerical stability during matrix factorization.

03

Residuals

Check \(r=Ax-b\) to evaluate the quality of a computed solution.

04

Tolerances

Tolerances determine when values should be treated as numerically zero.
