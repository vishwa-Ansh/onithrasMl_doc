scipy.linalg

solve

Solve a linear system of equations of the form Ax = b.

Available in OnithrasML

Overview

solve computes the solution x of a square linear system:

A x = b

The function is intended for solving linear systems directly rather than explicitly computing the inverse of A.

i
Prefer solving over inversion

When you need to solve Ax = b, using solve is generally more efficient and numerically preferable to computing inv(A) first.

Signature

Python

    a,
    b,
    lower=False,

API Reference

Parameters

The solve() function accepts a coefficient matrix, a right-hand side, and optional configuration parameters that control how the linear system is solved.

a required
array-like

The coefficient matrix of the linear system. The matrix represents the left-hand side of the equation:

A x = b

For a standard linear system, a must be a square two-dimensional array.

Expected shape: (N, N)
Example 
A = np.array([
    [3., 2.],
    [1., -1.]
])
b required
array-like

The right-hand side of the linear system. It contains the values that the matrix equation must produce.

A one-dimensional vector represents a single right-hand side. A two-dimensional array can represent multiple right-hand sides that share the same coefficient matrix.

Accepted shapes: (N,) or (N, NRHS)
Single right-hand side 
b = np.array([
    2.,
    4.
])
lower
bool, default=False

Determines which triangular portion of the matrix should be considered when a structured symmetric, Hermitian, or positive-definite matrix is being solved.

When lower=False, the solver uses the upper triangle.

When lower=True, the solver uses the lower triangle.

Example 
x = solve(
    A,
    b,
    lower=True
)
overwrite_a
bool, default=False

Allows the solver to overwrite the input coefficient matrix a when possible.

This option can reduce temporary memory usage and may improve performance because the solver does not necessarily need to preserve the original matrix.

Important

Do not enable this option when you need the original matrix after the solve.

overwrite_b
bool, default=False

Allows the solver to overwrite the right-hand side b when possible.

This can reduce memory allocations during computation, especially when working with large arrays.

check_finite
bool, default=True

Determines whether the input arrays are checked for non-finite values such as NaN and Inf.

Keeping this enabled provides safer input validation.

Disabling the check can improve performance when the caller already guarantees that the input contains only finite values.

Performance trade-off

Disabling validation should only be considered when the input has already been validated. Passing invalid numerical data to a low-level solver can result in undefined numerical behavior.

assume_a
str or None

Describes the known mathematical structure of the coefficient matrix.

Supplying structural information can allow the implementation to select an algorithm that is better suited to the matrix.

general No special structure is assumed.
diagonal Non-zero values occur only on the diagonal.
triangular Matrix is upper or lower triangular.
symmetric Matrix satisfies A = Aᵀ.
positive definite Matrix is symmetric positive definite.
transposed
bool, default=False

If enabled, solves the transposed system:

Aᵀ x = b

This can be useful when the transpose of the coefficient matrix is required without explicitly constructing a separate matrix.

Matrix structure

If the structure of the matrix is known, OnithrasML can use that information to select a more appropriate numerical algorithm.

Diagonal

Symmetric

Returns

x
ndarray

The solution of the linear system Ax = b.

Numerical stability

Linear-system solvers are sensitive to the conditioning of the coefficient matrix. A matrix that is nearly singular can produce a solution that is highly sensitive to small perturbations in the input.

residual = ‖Ax − b‖

After solving, the residual can be used to check how accurately the computed solution satisfies the original system.

Ill-conditioned systems

A small residual does not always imply that the computed solution is highly accurate. Conditioning of the problem should also be considered.

Errors and validation

ValueError

Raised when the input shapes are incompatible or the coefficient matrix is not square.

LinAlgError

Raised when the system cannot be solved because the matrix is singular or the numerical factorization fails.

LinAlgWarning

May be emitted when the matrix is detected to be poorly conditioned.

Example 01

Solve a basic linear system

Consider the system:

3x + 2y = 2
x − y = 4
solve_example.py 
import numpy as np
from onithrasml.linalg import solve

A = np.array([
    [3., 2.],
    [1., -1.]
])

b = np.array([
    2.,
    4.
])

x = solve(A, b)

print(x)
Output 
[ 2. -2.]
Example 02

Multiple right-hand sides

The right-hand side can contain multiple columns. Each column represents an independent system with the same coefficient matrix.

multiple_rhs.py 
import numpy as np
from onithrasml.linalg import solve

A = np.array([
    [4., 2.],
    [1., 3.]
])

B = np.array([
    [10., 4.],
    [7., 9.]
])

X = solve(A, B)

print(X)
Example 03

Verify the solution

A simple way to verify a computed solution is to substitute it back into the original equation.

verification.py 
import numpy as np
from onithrasml.linalg import solve

A = np.array([
    [3., 2.],
    [1., -1.]
])

b = np.array([2., 4.])

x = solve(A, b)

residual = A @ x - b

print(residual)
print(np.allclose(A @ x, b))
Expected True
Example 04

Solve a 3 × 3 system

For larger systems, the same interface is used. The coefficient matrix must contain one row for each equation and one column for each unknown.

2x + y + z = 5
4x + 5y + 2z = 14
x + 2y + 4z = 13
solve_3x3.py 
import numpy as np
from onithrasml.linalg import solve
A = np.array([
    [2., 1., 1.],
    [4., 5., 2.],
    [1., 2., 4.]
])
b = np.array([5.,14.,3.])
x = solve(A, b)
print(x)
Output 
[1. 2. 3.]
Example 05

Solve multiple right-hand sides

Sometimes the coefficient matrix remains unchanged while several different right-hand sides must be solved. In that situation, the columns of B represent separate systems.

AX = B
multiple_systems.py 
import numpy as np
from onithrasml.linalg import solve
A = np.array([
    [3., 1.],
    [1., 2.]
])
B = np.array([
    [9., 4.],
    [8., 5.]
])
X = solve(A, B)
print(X)

Here B[:, 0] represents the first system and B[:, 1] represents the second system. Both systems use the same matrix A.

Example 06

Check the residual

After computing a solution, you can evaluate the residual to determine how closely the computed solution satisfies the original system.

r = Ax − b
residual.py 
import numpy as np
from onithrasml.linalg import solve
A = np.array([
    [4., 1.],
    [2., 3.]
])
b = np.array([
    9.,
    13.
])
x = solve(A, b)
residual = A @ x - b
print("solution:", x)
print("residual:", residual)
✓
What should you expect?

For a well-conditioned system solved with floating-point arithmetic, the residual should generally be close to zero, subject to numerical rounding.

Example 07

Verify the solution with allclose

Exact equality is usually not appropriate for floating-point numerical calculations. Instead, use a tolerance-aware comparison such as np.allclose().

verify.py 
import numpy as np
from onithrasml.linalg import solve
A = np.array([
    [3., 2.],
    [1., -1.]
])
b = np.array([
    2.,
    4.
])
x = solve(A, b)
is_valid = np.allclose(
    A @ x,
    b
)
print(is_valid)
Result True
Example 08

Handling a singular matrix

A singular matrix does not have a unique inverse and a corresponding linear system cannot be solved using the standard direct solver.

singular.py 
import numpy as np
from onithrasml.linalg import solve
A = np.array([
    [1., 2.],
    [2., 4.]
])
b = np.array([
    3.,
    6.
])
try:
    x = solve(A, b)
    print(x)
except np.linalg.LinAlgError:
    print("Matrix is singular.")
Why does this fail?

The second row is exactly two times the first row. Therefore, the matrix does not contain enough independent information to determine a unique solution.

Under the hood

How solve() works

Conceptually, solving a linear system means finding a vector x for which the matrix multiplication A @ x produces b.

01
Validate inputs

Check dimensions, data types and numerical validity of the input arrays.

02
Analyze matrix structure

If structural information is available, a specialized numerical method may be used.

03
Factorize the matrix

A numerical factorization transforms the original system into forms that are easier to solve.

04
Compute the solution

The resulting factors are used to obtain the solution vector or matrix.

05
Return x

The computed solution is returned as an array with the appropriate shape.

Choosing the right solver

Problem Recommended Reason
General system solve() General-purpose linear system.
Triangular system solve_triangular() Exploits triangular structure.
Repeated solves factor + solve Reuse matrix factorization.
Least squares lstsq() Appropriate when the system is overdetermined or underdetermined.
