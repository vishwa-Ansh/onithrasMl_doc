INTRODUCTION

The numerical foundation for matrix-based computation.

Linear algebra is one of the fundamental building blocks of numerical computing. Vectors and matrices are used to represent data, transformations, linear systems, optimization problems, simulations, and many machine-learning algorithms.

The OnithrasML linear algebra API provides numerical routines for solving systems, computing matrix properties, performing decompositions, constructing matrix functions, and working with structured matrices.

!
Prefer specialized numerical routines

If your goal is to solve \(Ax=b\), use linalg.solve() instead of explicitly computing \(A^{-1}\).

BASIC ROUTINES

Core matrix operations

These routines cover the most common operations required when working with numerical matrices and vectors.

linalg.inv() Compute the inverse of a square matrix
BASIC

Compute the inverse \(A^{-1}\) of a square matrix \(A\), where the inverse satisfies

\[ AA^{-1} = A^{-1}A = I \]

The matrix must be square and nonsingular. If the matrix is singular, an inverse does not exist.

Example

inverse.py
Python
1 2 3 4 5 6 7 8 
import numpy as np
from onithrasml import linalg

A = np.array([
    [1.0, 3.0],
    [2.0, 4.0]
])

A_inv = linalg.inv(A)
OUTPUT
[[-2.   1. ]
 [ 1.  -0.5]]
Numerical advice

Explicit inversion is often unnecessary. To solve \(Ax=b\), prefer linalg.solve().

linalg.solve() Solve a linear system
SOLVER

Solve a linear system of equations

\[ Ax=b \]

where \(A\) is the coefficient matrix, \(x\) is the unknown vector, and \(b\) is the right-hand side.

Example

solve.py
Python
1 2 3 4 5 6 7 8 9 
import numpy as np
from onithrasml import linalg

A = np.array([
    [1.0, 2.0],
    [3.0, 4.0]
])

b = np.array([5.0, 6.0])

x = linalg.solve(A, b)
OUTPUT
[-4.   4.5]
Recommended

Use a solver instead of computing \(A^{-1}b\). A dedicated solver avoids unnecessary matrix inversion and is generally more numerically appropriate.

linalg.det() Compute a matrix determinant

linalg.lstsq() Solve a linear least-squares problem
SOLVER

Least squares finds an approximate solution when an exact solution may not exist.

\[ \min_x \|Ax-b\|_2^2 \]

This is widely used in regression, curve fitting, parameter estimation, optimization, and machine learning.

least_squares.py
Python
1 2 3 4 5 6 7 8 9 
import numpy as np
from onithrasml import linalg

A = np.array([
    [1., 1.],
    [1., 2.],
    [1., 3.]
])

b = np.array([2., 2.9, 4.1])

x, residuals, rank, s = \
    linalg.lstsq(A, b)

DECOMPOSITIONS

Break complex matrices into useful structures.

Matrix decompositions rewrite a matrix into simpler components. These representations are fundamental to numerical solvers, statistics, optimization, signal processing and machine learning.

linalg.eig() Eigenvalues and eigenvectors
DECOMPOSITION

An eigenvector \(v\) of a matrix \(A\) satisfies

\[ Av = \lambda v \]

where \(\lambda\) is the corresponding eigenvalue.

eigen.py
Python
1 2 3 4 5 6 7 8 
import numpy as np
from onithrasml import linalg

A = np.array([
    [1., 2.],
    [3., 4.]
])

values, vectors = \
    linalg.eig(A)
Common applications

Eigenvalue problems appear in stability analysis, dimensionality reduction, differential equations, graph algorithms, and spectral methods.

linalg.svd() Singular Value Decomposition
DECOMPOSITION

Singular Value Decomposition represents a matrix as

\[ A = U\Sigma V^T \]

SVD is useful for low-rank approximation, dimensionality reduction, numerical analysis, and least-squares problems.

    linalg.svd(A)

NUMERICAL ANALYSIS

Numerical stability is part of the algorithm.

Floating-point arithmetic introduces rounding error. A mathematically correct algorithm is not necessarily numerically reliable for every input.

01

Avoid unnecessary inverse

Prefer solving a system directly rather than explicitly computing the inverse matrix.

02

Check residuals

After solving \(Ax=b\), verify the residual \(r=Ax-b\).

03

Understand conditioning

Ill-conditioned matrices can amplify small perturbations in input data.

\[ r = Ax-b \]
